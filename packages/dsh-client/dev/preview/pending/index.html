③ action 的字符串输出 —— 形状还没定 等你定形状

你的要求：「action 对应的字符串输出应该是在模板里面写一起的，就在模板包里面跟着 action 的定义描述这个 json 怎么对应的文字输出。而 ai tool 看 action 应该是接入这个接口的。」
现状：packages/tools/src/format.ts 和 packages/dsh/src/tools.ts:163 各有一份「取 value 字段，取不到就压成 JSON」的胶水，没有按 action 分派的正式输出。

要你定：这个「payload → 文字」用什么形状放进 ActionDef。三个候选（选一个，或说你自己的想法）：

A · 函数式
每个 action 一个 toText(payload) => string，写在 ActionDef 里。
{ $type:'text', toText: (p) => p.value ?? '' }
优点：想怎么算都行；缺点：模板 YAML 里看不到文案。
B · 声明式
模板里写字段映射，比如 toText: "{{value}}" 或 { "value": "正文", "placeholder": "灰字" }。
优点：文案在模板里可见、可改；缺点：表达力弱（ask 这种要拼多选项的就难写）。
C · 混合
ActionDef 给函数兜底，模板可以覆盖。
优点：通用 + 可定制；缺点：两处都能写，容易漂。
