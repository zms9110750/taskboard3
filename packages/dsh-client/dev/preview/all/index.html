三个 action 的组件页（真组件 + 真 state）

text · 三相位
产品组件 Section / TextBlock。create 的折叠区灰字和正文框是同一份数据；三栏共享 payload，改一栏另外两栏跟着变。
markdown · 三相位
产品组件 Section / MarkdownBlock。create 源码框 + 「查看预览」，active / ended 只读渲染；改源码另外两栏跟着变。
ask · 三相位
产品组件 AskGroupCard。create 是问卷编辑器，active 可作答（圆圈/方框、自填、未选择），ended 只读（勾 + 左侧竖线）。
