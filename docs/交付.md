## 2. 插件本体（交付物）

### 2.1 是什么

`taskboard3` = 一个 **Cordis 插件 bundle**。装进 DSH profile 后提供：

```
① 任务板（科技树视图 / 列表视图 / 详情 / 抽屉 / 工作区）
② 工具权限（组图 / 工具清单 / 模板授权 三个页签）
③ 侧栏入口（任务板、工具权限）
④ 输入框里的权限浮层入口
```

### 2.2 包结构

```
packages/
  protocol/         词汇与判决（9 状态 / 4 组 / 6 关系 / 错误码）
  core/             领域逻辑 + CardStore 端口 + ToolPolicyStore
  tools/            AI 工具定义层（v2，纯 JSON Schema）
  io/               SQLite 封装
  store/            存储实现（Cordis 插件行，可替换）
  dsh-core/         Host 侧公共设施
  dsh-tools/        AI 工具的 DSH 适配
  dsh-agent-guard/  DSH 专属：工具档位权限 + /api/tools + 工具守卫
  dsh/              Host 半边：HTTP 路由 + 命令
  dsh-client/       客户端 UI（右侧工作区 + 侧栏 + 输入框）
  bundle/           一个 bundle 壳：cordis.patch.yml 里 6 行 insert
```

### 2.3 构建与测试（唯一验收入口）

```powershell

# ① 10 个包的 TypeScript 构建（顺序即依赖顺序，别改）

  packages/protocol packages/core packages/tools packages/io packages/store `
  packages/dsh-core packages/dsh-tools packages/dsh-agent-guard packages/dsh packages/dsh-client

# ② dev/ 暂存区单独检查（AGENTS 规则 7：tsc -b 不含 dev/）
node node_modules/typescript/bin/tsc -p packages/dsh-client/tsconfig.dev.json

# ③ 测试的 tsconfig
```

### 3.2 启动 web（真验证的唯一方式）

```powershell
$env:DSH_HOME='X:\temp\dsh\tb3-home'
& 'B:\DeepSeek Harness\0.2.2-rc2\resources\runtime\cli\bin\dsh.cmd' `
    --profile tb3-isolated --port <端口> --no-open
```

- 启动成功会打印一行：`dsh web: http://127.0.0.1:<端口>/?token=<token>`
- **token 每次启动都变**，别复用旧的
- **端口**：历史上子 AI 习惯用 `50700–51000`，并会把该区间当成自己的清理范围（**会 kill 掉别人的 profile**）。

- `/taskboard3/api/*` 需要 cookie：先 `GET /?token=<token>`，复用返回的 `Set-Cookie`；不带 cookie 直接打 API 是 **401**
