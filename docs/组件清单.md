## 〇、三层分离（`2026-11-17` 用户要求）

用户：
> 「开发中的组件放在 dev 文件夹。组件，展示组件的 html，都分开。
>  在确认组件可用以后再把 ts 放回去 src」

```
packages/dsh-client/
├─ src/          ← 产品代码（打进插件、发 npm）
├─ test/         ← 产品代码的测试
└─ dev/          ← 开发中，完全不参与产品构建
   ├─ pure/       ┐
   ├─ components/ ├ 组件本体（未定稿）
   ├─ test/       ┘
   ├─ preview/    ← 展示脚手架（入口 / CSS / 构建 / 验证）+ index.html
   └─ shots/      ← verify 跑出来的截图
```

**为什么**：`src/preview/main.tsx` 放在 `src/` 下时，`tsc -b` 给它出了
`lib/preview/main.d.ts`，而 `files: ["lib"]` 会把它发到 npm。

**构建**：

```powershell
# 组件本体 + 单测（在 dev 里）
node packages/dsh-client/dev/preview/build.mjs     # → dev/preview/index.html（双击看）
node packages/dsh-client/dev/preview/verify.mjs    # CDP 断言
node --test packages/dsh-client/dev/test/*.test.ts # 纯逻辑单测

# 产品（不含 dev）
tsc -b packages/*                                  # dev/ 不在 include 里
```

## 一、为什么按这个顺序

**依赖序**，不是重要性序：

```
pure（纯逻辑，可单测）
  ↓
叶子组件（不依赖别的组件）
  ↓
复合组件（拼叶子）
  ↓
视图（拼复合）
```

⇒ 越靠前的越先做，因为后面的**没有它编译不过**（不是「不好看」）。

| 攻击 | 结果 |
|---|---|

| `<img onerror>` / `![alt](url)` | 只剩 `p`，无 `onerror` 属性 |

| `[x](javascript:...)` / `jav&#x61;script:` / 大小写 / 前置空白 / 制表符 | 拆标签只留 `x` |
| `data:` / `vbscript:` / `//evil.com`（协议相对外站）| 拦 |

| 原始 HTML 的 `on*` 属性 | 一个都进不来（属性白名单：class/align/href/target/rel/data-lang）|
| http(s) / mailto / 站内相对 | 放行 + 统一 `target=_blank rel="noopener noreferrer"` |

**支持的 GFM**：标题（#/setext）、粗斜删、行内码、硬换行、列表（嵌套/有序/任务）、

⚠ **它踩的一个坑值得全员知道**：预览产物要内联进 `<script>`，必须转义两个序列
（`</script` **和** `<!--`）。只转第一个不够 —— `<!--` 会让 HTML tokenizer 进 escaped
状态，之后真正的 `</script>` 不再关标签 ⇒ **页面白屏、控制台零报错**。

| 备注常驻 | 6 个场景逐个断言节点存在**且可见** |
| 没有「正文」二字 | 全页 `innerText` 不含 + 无 `.detail-body` 节点，**并配对照断言**（页面确实含「备注」「历史」）防空跑 |
| 历史折叠 | 0 条整块不出现 / 1 条直接展开且**不画折叠按钮** / 3 条初始收起、能开能合 |

**历史折叠的判断（成员给的，我认可）**：
- 用户只说「可以折叠」，没说必须
- 详情一屏有限，历史是只读记录极少反复看，而章节/备注要读要写
- 旧版 3 条以上就常驻展开 —— 用户的描述正是「占满一屏」
- ⇒ **≥2 条才给折叠**；1 条直接展开且不画折叠按钮（「点了没反应的按钮比没有更困惑」）

**它的踩坑记录里有两条值得抄**：
1. **CDP `click()` 必须先 `scrollIntoView`** —— 靠后的面板在视口外，按 rect 算的坐标点下去是空白，导致「展开历史」3 条全红而代码是对的
2. **预览页自己的说明文字含「正文」⇒ 被「不许出现正文」的断言打红** —— 删掉说明里那两字，断言才有意义
